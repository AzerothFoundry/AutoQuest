# AutoQuest

A lightweight World of Warcraft 1.12 addon for Turtle WoW that automates quest interactions.

## Features
- **Auto-Accept Quests**: Automatically accepts quests from NPC Gossip or Greeting windows.
- **Auto-Progress Quests**: Automatically moves through quest progression screens.
- **Smart Auto-Turn-In**: Automatically turns in quests and selects rewards if there is only zero or one option. If multiple rewards are available, it pauses for manual selection.
- **Shift-Key Bypass**: Hold the **SHIFT** key while interacting with an NPC to temporarily disable all automation.
- **Slash Commands**:
  - `/aq toggle` - Toggle the entire addon on/off.
  - `/aq accept` - Toggle automatic quest acceptance.
  - `/aq turnin` - Toggle automatic quest turn-in.

## Installation
1. Download the repository.
2. Extract the `AutoQuest` folder into your `Interface/AddOns` directory.
3. Ensure the folder name is exactly `AutoQuest`.
